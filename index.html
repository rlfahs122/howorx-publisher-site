HOWORX Publishing Client

HOWORX Publishing Client is a private tool used by the HOWORX channel operator to prepare, organize and publish educational science and engineering videos. It is not offered as a public sign-up service.

What the client does

  • Reads selected HOWORX production files and job records from the operator's Google Drive, and stores production outputs and records in the operator's project folders
  • Uploads authorized videos to the operator's HOWORX YouTube channel using YouTube API Services
  • Sets or updates authorized video information, thumbnails, captions, visibility, publication schedules and altered or synthetic content disclosures
  • Checks the channel, processing status and publication result, and retains job records to reduce duplicate uploads
  • Provides a separately authorized read-only analytics feature for aggregate channel and video performance

The current workflow combines owner-controlled cloud preparation with local publishing steps. Fully unattended cloud publishing is under evaluation. Japanese audio-track registration uses a separate YouTube Studio step.

Google authorization

The operator grants access through Google OAuth. Requested permissions depend on the enabled workflow. The current cloud authorization configuration includes full Google Drive access and YouTube management access; these are broader than access to one selected file or permission only to upload a video.

The client does not request a Google password. Review the Privacy Policy and Terms of Use before authorizing or using the client.
