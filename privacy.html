Privacy Policy

Effective 27 September 2026. This policy covers the HOWORX Publishing Client, an internal tool used by the HOWORX channel operator. It does not cover YouTube itself or other Google services.

Authorization and data accessed

The operator authorizes access through Google OAuth. The client does not ask for or store a Google password. With the operator's permission, it accesses the authorized channel identity, uploads videos and metadata, and checks upload processing and visibility. A separately authorized read-only analytics path can retrieve aggregate channel and video performance, including views, engaged views, likes, comment counts, subscriber gains, audience geography, and traffic-source totals. The client does not retrieve viewer identities or comment text.

Google's Privacy Policy governs Google's processing. You may review and revoke this client's access in Google Account permissions.

Purpose and sharing

The client uses these data to publish finished videos to the operator's channel, prevent duplicate uploads, verify processing and visibility, and evaluate aggregate video performance. It does not sell YouTube API data or offer accounts to third-party creators. Uploads and related metadata are sent to YouTube through YouTube API Services. The operator does not share stored OAuth tokens or API data with advertisers.

Storage and retention

In the current owner-only local deployment, OAuth credentials, upload receipts, and analytics snapshots are stored on the operator's computer in project data files excluded from the public source repository. They are not published on this website. The client can also retain YouTube video IDs and upload status in local job records to prevent duplicate publication. Cloud-hosted unattended operation is a future plan, not the deployment described here; this policy will be updated before such operation begins.

The operator periodically reviews stored YouTube API data and deletes or refreshes data that the applicable YouTube API rules no longer permit to be retained. OAuth credentials are kept only while the authorization is needed. Local copies may remain until the operator completes a deletion request or ends use of the client. Published videos remain subject to YouTube's own controls and retention rules.

Access revocation and deletion

The operator can revoke Google authorization at any time through Google Account permissions. To request deletion of data held by the client, email contact.bidnis@gmail.com. The operator will revoke the relevant OAuth grants and delete locally stored YouTube API data within seven days of a verified request, and will report any item that cannot be deleted immediately. This includes local upload receipts, analytics snapshots, and YouTube API fields in job records. Revoking or deleting client data does not itself delete a video already published on YouTube; use YouTube's own controls for that.

The current deployment has no separately operated cloud copy of these OAuth credentials or API data. If storage or backup practices change, this policy and the deletion procedure will be updated before migration.

Your choices and contact

Only the channel operator uses this client. The operator can stop using it, revoke authorization, or request a copy or deletion of data stored by the client. For privacy questions, contact contact.bidnis@gmail.com. Never email passwords, authorization codes, or OAuth tokens.

Use of YouTube through the client is also subject to the YouTube Terms of Service.
